# 나의 여행 선반 (어드민 + 사이트)

다녀온 곳을 사진과 함께 기록하면, 액자에 넣은 여행 사진이 나무 선반에 놓인 사이트가 만들어진다. 버킷리스트 클럽 7회차 실습용 책장 템플릿(클럽장의 책장 https://byminseok.com/shelf-portrait/ 에서 구조를 가져옴)을 여행 기록으로 바꾼 것이다.

폴더는 두 쪽으로 나뉜다.

| 쪽 | 폴더 | 어디서 열리나 | 하는 일 |
| --- | --- | --- | --- |
| 어드민 | `admin/` | 내 컴퓨터에서만 | 여행을 기록하고, 사진을 올리고, 고치고, 게시한다 |
| 사이트 | `docs/` | 웹 (GitHub Pages) | `shelf.json` 하나를 읽어서 선반을 그린다 |

## 켜기

`run.command`(Windows는 `run.bat`)를 더블클릭한다. 어드민이 브라우저에 열린다. 또는 터미널에서

```bash
python3 admin/server.py      # http://127.0.0.1:8798
```

어드민 오른쪽 위의 "사이트 미리보기"를 누르면 웹에 올라갈 화면을 내 컴퓨터에서 먼저 볼 수 있다. 끌 때는 터미널 창에서 Ctrl+C. 파이썬 표준 라이브러리만 써서 따로 설치할 것이 없고, API 키도 필요 없다.

## 기록 한 건에 남기는 것

| 칸 | 이름 | 적는 법 |
| --- | --- | --- |
| 사진 | `photo` | "사진 고르기". 없어도 된다. 없으면 엽서 카드로 나간다 |
| 장소 | `place` | 꼭 적는다. 예: 트롬소 오로라 |
| 나라, 도시 | `country`, `city` | 예: 노르웨이, 트롬소 |
| 다녀온 날 | `date` | `2025-03-14`, `2025-03`, `2025` 처럼 아는 만큼. 모르면 비워 두면 "날짜 미정" 칸에 놓인다 |
| 메모 | `memo` | 그날의 기억 |
| 다시 가고 싶은 곳 | `fav` | 체크하면 액자에 빨간 핀이 꽂힌다 |

사진은 올리기 전에 브라우저에서 긴 쪽 1200px JPG로 줄인다. 이때 사진 속 위치 정보(GPS)와 촬영 정보는 빠진다. 줄인 사진은 `docs/photos/`에 저장된다.

## 기록하고 웹에 올리기까지

```
① 기록하기(사진 + 칸 채우기) → ② 사이트 미리보기로 확인 → ③ 게시 → ④ GitHub에 올리기(push)
```

어드민에서 적고 고친 것은 `data/trips.json`에 저장된다. **게시**를 눌러야 사이트가 읽는 `docs/shelf.json`이 새로 써진다. 고치는 중인 것이 바로 웹에 나가지 않게 두 걸음으로 나눴다. 게시한 다음 push 하면 1~2분 뒤 웹에 반영된다.

Claude에게 "선반을 게시했어. 바뀐 파일을 커밋하고 GitHub에 올려줘"라고 하면 된다. 직접 한다면

```bash
git add .
git commit -m "여행: 새 기록"
git push
```

주소는 `https://[내 GitHub 아이디].github.io/[저장소 이름]/` 이다.

**저장소는 공개다.** `docs/`의 사진만이 아니라 `data/trips.json`의 메모, 어드민 코드까지 누구나 볼 수 있다. 집 주소, 남의 얼굴, 숙소 이름처럼 공개하기 싫은 것은 적거나 올리지 않는다.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `admin/server.py` | 어드민 서버. 기록 저장, 사진 저장, 게시 |
| `admin/admin.html` | 어드민 화면 |
| `data/trips.json` | 내 여행 기록 원본. 어드민이 쓴다 |
| `docs/index.html` | 사이트 화면. 디자인은 마음대로 바꿔도 된다. 색과 크기만 살짝 바꿀 때는 맨 위 `:root`의 값을 고치면 전체에 반영된다 |
| `docs/shelf.json` | 사이트가 읽는 파일. 게시 버튼이 만든다. 손으로 고치지 않는다 |
| `docs/photos/` | 올린 사진. 기록을 빼거나 사진을 바꾸면 예전 파일은 어드민이 지운다 |
| `만든-과정.md` | 원래 책장 템플릿을 만든 과정 |

## 내 것으로 바꾸기

**디자인은 완전히 내 마음대로 바꿔도 된다.** 사이트가 `shelf.json`만 읽기 때문에 색, 글꼴, 배치를 전부 바꿔도 어드민과 게시는 그대로 돌아간다. Claude에게 이 README를 읽히고 바꾸고 싶은 것을 말하면 된다. 예를 들면

- "선반 말고 지도 위에 핀으로 보여 줘. 어드민은 그대로 두고 docs/index.html만"
- "기록마다 '누구와 갔는지' 칸을 더해 줘. 어드민 입력 칸, 저장, 게시, 사이트 상세 창까지"
- "나라별로 묶어서 보여 줘"

칸을 더할 때는 `admin/server.py`의 `FIELDS`와 `PUBLIC_FIELDS`, `admin/admin.html`의 입력 폼, `docs/index.html`의 상세 창을 같이 고친다.
