2. 웹에 올리기

게시를 누르면 docs/shelf.json이 새로 써져요. 여기까지는 내 컴퓨터 안의 일이에요. 사이트 미리보기로 확인한 뒤 GitHub에 올리면 웹에 반영돼요.

Claude Code(코덱스)에게 이렇게 말하면 돼요.

선반을 게시했어. 바뀐 파일을 커밋하고 GitHub에 올려줘.

직접 한다면 터미널에서

git add .
git commit -m "여행: 새 기록"
git push

올린 사진(docs/photos/)과 메모는 공개 저장소라 누구나 볼 수 있어요. 집 주소나 얼굴처럼 남에게 보이기 싫은 것은 올리지 마세요. push 하고 1~2분 뒤에 사이트가 바뀌어요.
